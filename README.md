# Esercizio 2x02 JavaScript – Assistenza telefoni

Modulo per un centro assistenza di telefoni cellulari: i dati inseriti nel form generano una ricevuta di consegna stampabile; il pulsante "Torna al form" ripristina il modulo vuoto per un nuovo cliente.

Aprire `index.html` nel browser.
